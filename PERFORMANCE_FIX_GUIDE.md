## ?? **Reference Documentation**

### Visual Studio Optimization Flags:
- `/O2` - Optimize for speed
- `/Oi` - Enable intrinsic functions
- `/Oy` - Omit frame pointer
- `/Ot` - Favor code speed
- `/GL` - Whole program optimization
- `/OPT:REF` - Remove unreferenced data
- `/OPT:ICF` - Fold identical COMDAT

### OpenCV Build Types:
- `opencv_world4120d.lib` - Debug (slow, large)
- `opencv_world4120.lib` - Release (fast, small)
